# Power BI

Interactive dashboards built with Microsoft Power BI Desktop. Open the `.pbix` files with [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free, Windows).

| File | Description |
|---|---|
| `HR_Dashboard.pbix` | **HR Dashboard** — one report page with 6 slicers for filtering, 7 KPI cards, a line chart, two donut charts, a bar chart and a detail table |
| `HR_DATA.pbix` | Data-preparation file for the HR dataset (imported data model, no report page) |
| `Covid_Trade_Dashboard.pbix` | **Trade Dashboard** — effects of COVID-19 on trade, built from the open dataset "Effects of COVID-19 on trade at 15 December 2021 (provisional)": 5 KPI cards, a bar chart and a detail table |
| `effects-of-covid-19-on-trade-at-15-december-2021-provisional after edit.pbix` | Data-preparation file for the COVID-19 trade dataset after editing (no report page) |

Skills practiced: importing and cleaning data, data modeling, interactive visuals (slicers, KPI cards, charts) and dashboard layout.
