## Small AI apps and NLP

| File | Topic |
|---|---|
| `modelai (1).ipynb` | Trains a small Keras symptom-based diagnosis model and converts it to TensorFlow Lite (`medical_diagnosis_model.tflite`) |
| `فلاتر_مودل (1).ipynb` | Trains a scikit-learn decision tree (saved with joblib) and a Keras model converted to TensorFlow Lite, prepared for a Flutter mobile app |
| `app.py` | Desktop symptom checker (Tkinter) that loads the TensorFlow Lite model and suggests flu, migraine or food poisoning from four symptoms. The `.tflite` file is not included — generate it with `modelai (1).ipynb`. |
| `data_nlp.ipynb` | NLP experiment on the reduced CodeSearchNet dataset from Kaggle |

> The symptom checker is a learning project, not a medical tool.
